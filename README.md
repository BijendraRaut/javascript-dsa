# JavaScript DSA

A collection of JavaScript DSA problems solved for interview preparation.

## Topics

- Strings
- Arrays
- Objects
- Searching
- Sorting
- Recursion

Phase 1 (Days 1-3): Rebuild confidence

Your only goal is to get comfortable writing code again.

Solve these first:

Reverse a String
Reverse Each Word in a String
Find Number of Characters
Count Characters
Remove Given Character
Remove Whitespaces
Find Number of Words
Find Shortest Word
Convert String to Character Array
Unique Characters

These questions mainly use:

for loops
split()
join()
slice()
substring()
objects
arrays

Don't worry about optimization yet.

Phase 2 (Days 4-7): Hash Maps (Most Important)

If I had to pick one topic that appears in almost every JavaScript interview, it'd be Objects/Map for frequency counting.

Solve:

Character occurrence
First non-repeating character
Most frequent character
Anagrams
Remove duplicates
Property frequency
Maximum value from object
Group array by category
Collect books from objects

By the end of this phase you should instantly think:

"This looks like a hash map problem."

Separate palindrome numbers

reduce

Learn the Patterns Instead of Memorizing

Almost every JavaScript interview question falls into one of these patterns.

Pattern Questions
Frequency Counter Anagram, Character Count, First Non-Repeating
Two Pointers Palindrome, Move Zeros
Sliding Window Longest Substring
Hash Map Two Sum, Group By
Sorting Maximum Product, Anagram
Binary Search Search in Sorted Array
Recursion Flatten Array
String Manipulation Reverse, Camel Case, Compression

Once you recognize the pattern, solving becomes much easier.
